# Wiki Circular 2026

Sitio estático preparado para desplegar directamente en Vercel.

## Archivos

- `index.html` — estructura de la web.
- `styles.css` — diseño responsive.
- `app.js` — contenidos, buscador, áreas, situaciones, calendario y contactos.

## Despliegue en Vercel

No requiere Node.js, build command ni variables de entorno.

1. Subir esta carpeta a un repositorio de GitHub.
2. En Vercel seleccionar `Add New Project`.
3. Importar el repositorio.
4. Framework Preset: `Other`.
5. Build Command: dejar vacío.
6. Output Directory: `.` o dejar la configuración por defecto.
7. Deploy.

También se puede desplegar con Vercel CLI desde esta carpeta:

`vercel`

## Criterio de contenido

La información está organizada a partir de la Circular Inicio Ciclo Lectivo 2026. Cuando la circular remite a otra normativa o instructivo y no desarrolla el procedimiento completo, esta versión no inventa pasos adicionales.
